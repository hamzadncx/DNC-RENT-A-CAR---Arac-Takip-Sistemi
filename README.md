# 🚗 DNC Rent A Car - Araç Kiralama ve Filo Yönetim Sistemi

Bu proje, PHP ve MySQL kullanılarak geliştirilmiş kapsamlı bir Araç Kiralama (Rent A Car) otomasyonudur. Müşteri kayıtlarından araç filosunun durumuna, sözleşme yazdırılmasından servis/bakım geçmişine kadar bir oto kiralama firmasının tüm dijital süreçlerini yönetmek amacıyla tasarlanmıştır.

## 🌟 Temel Özellikler

* **👥 Müşteri Yönetimi:** Yeni müşteri kaydı oluşturma, listeleme, güncelleme ve silme işlemleri.
* **🚘 Araç Filosu:** Araçların sisteme eklenmesi, plaka/model bazlı takibi ve müsaitlik durumlarının (Boşta / Kirada) anlık kontrolü.
* **📄 Kiralama ve Sözleşme:** Müsait araçların müşterilere kiralanması, otomatik toplam tutar hesaplaması ve **Tek Tuşla Resmi Sözleşme Yazdırma (A4 Formatında)** özelliği.
* **🔧 Bakım ve Servis Takibi:** Araçların periyodik bakımlarının, yapılan işlemlerin ve servis maliyetlerinin tarih bazlı kayıt altında tutulması.
* **💻 Modern ve Esnek Arayüz:** Kullanıcı dostu kenar çubuğu (sidebar) tasarımı ve Flexbox ile desteklenmiş, kaymayan tablo/buton yapıları.

## 🛠️ Kullanılan Teknolojiler

* **Backend:** PHP 
* **Veritabanı:** MySQL
* **Frontend:** HTML5, CSS3, Flexbox
* **Geliştirme Ortamı:** XAMPP Localhost, Visual Studio Code
